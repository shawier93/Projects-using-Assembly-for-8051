# Age-Based Menu Demonstration

[Back to subject group](../README.md)

Demonstrate a menu that selects a stored response according to an age band or another menu choice.

## Implementations

The memory version stores a response code. LCD versions display the archived messages, with different port assignments. The Proteus-derived version is another source listing for the same type of menu.

| Implementation | Input | Output |
| --- | --- | --- |
| [LCD Port 0 Interface](lcd-port-zero-interface/README.md) | Stored values or prompted choices | LCD and internal result bytes |
| [Memory Age Band Selection](ram-age-band-selection/README.md) | Values stored in memory | Internal memory |
| [LCD Port 1 Interface](lcd-port-one-interface/README.md) | Stored values or prompted choices | LCD and internal result bytes |
| [Proteus Age Band Menu](proteus-age-band-menu/README.md) | See example | See example |
