## Applications

| Application | Description |
| --- | --- |

| [Keil C51 Startup Module](keil-c51-startup-module/README.md) | Initialize the configured memory and stack before a linked C program starts. |
| [Key Encoder Polling Sketch](key-encoder-polling-sketch/README.md) | Read a key from an encoder, wait for release, and repeat. The main loop does not send the decoded key to a display. |
