# Three Digit Arithmetic

[Back to subject group](../README.md)

Build a three-digit number, add its digits, and subtract that digit sum from the number.

## Implementations

Memory versions retain the result for inspection. LCD versions display its digits; some also flash an indicator. Several drafts contain malformed instructions, so the worked arithmetic must not be mistaken for a successful hardware test.
