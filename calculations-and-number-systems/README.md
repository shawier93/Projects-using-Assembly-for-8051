# Calculations and Number Systems

[Back to portfolio](../README.md)

Calculate values, convert number formats, and inspect how the 8051 represents results.

## Applications

| Application | Description |
| --- | --- |
| [Four Operation Calculator](four-operation-calculator/README.md) | Choose addition, subtraction, multiplication, or division for two numbers. |
| [Triangle Calculator](triangle-calculator/README.md) | Calculate a triangle’s area from its base and height, or its perimeter from three side lengths. |
| [Average Calculator and Binary Zero Counter](average-and-zero-bit-counter/README.md) | Either calculate the average of two numbers or count the zero bits in a binary value. These are two separate menu operations. |
| [Number Base Converter](number-base-converter/README.md) | Convert a binary or hexadecimal-position number into decimal digits. |
| [Three Digit Arithmetic](three-digit-arithmetic/README.md) | Build a three-digit number, add its digits, and subtract that digit sum from the number. |
| [Hexadecimal Addition Display](hexadecimal-addition-display/README.md) | Show an addition equation using hexadecimal digits on an LCD. |
| [Keypad Multiplication](keypad-multiplication/README.md) | Read two single-digit operands separated by a key and display their product. |
| [Number and Bit Operations](arithmetic-operations-menu/README.md) | Use a menu to explore addition, binary display, bit complement, and duplication operations. |
| [Number and Letter Transformations](number-and-letter-transformations/README.md) | Transform a number assembled from digits, or repeat a letter a chosen number of times. |
| [Perrin Sequence](perrin-sequence/README.md) | Generate a number sequence in which each new value is the sum of the values two and three places before it. Some versions also let you request a particular term. |
