# Number and Letter Transformations

[Back to subject group](../README.md)

Transform a number assembled from digits, or repeat a letter a chosen number of times.

## Implementations

The versions differ in stored versus entered digits, numeric formatting, and interrupt control. Despite the original “secret code” wording, these are number and character exercises, not encryption.
