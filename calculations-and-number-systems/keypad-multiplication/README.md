# Keypad Multiplication

[Back to subject group](../README.md)

Read two single-digit operands separated by a key and display their product.

## Implementations

This program demonstrates a fixed multiplication operation. It does not implement a general expression parser.

| Implementation | Input | Output |
| --- | --- | --- |
| [Keypad Product Display](keypad-product-display/README.md) | Keypad | LCD and internal result bytes |
