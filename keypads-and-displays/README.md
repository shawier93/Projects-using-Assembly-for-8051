# Keypads, Displays, and Serial Communication

[Back to portfolio](../README.md)

Read physical inputs and pass characters between the processor, LCD, and serial interface.

## Applications

| Application | Description |
| --- | --- |
| [Keypad And LCD Routines](keypad-and-lcd-routines/README.md) | Provide support routines that scan a keypad and write characters or commands to an LCD. |
| [Keypad Echo To LCD](keypad-echo-to-lcd/README.md) | Show a decoded key on the LCD, then wait for its release before accepting another press. |
| [Keypad Controlled LCD And Serial Output](keypad-controlled-lcd-and-serial-output/README.md) | Use an encoder key to select a message and send characters to the LCD and serial interface. |
| [Interrupt Driven Keypad Control](interrupt-driven-keypad-control/README.md) | Respond to an external interrupt by decoding a key and sending the selected message. |
| [Switch Controlled Serial And Keypad Display](switch-controlled-serial-and-keypad-display/README.md) | Use two switches to select serial echo or keypad processing. |
