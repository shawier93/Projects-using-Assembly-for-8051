# Timing and Control

[Back to portfolio](../README.md)

Compare dates and times, count events, and sequence output signals.

## Applications

| Application | Description |
| --- | --- |
| [Date Interval](date-interval/README.md) | Subtract two stored dates using separate day, month, and year fields. |
| [Travel Duration](travel-duration/README.md) | Subtract departure time from arrival time and format the elapsed hours and minutes. |
| [Traffic Light Sequencer](traffic-signal-controller/README.md) | Repeatedly send a sequence of signal patterns to three output ports. |
| [External Pulse Counter](external-pulse-counter/README.md) | Count external pulses and display the count when the display event is detected. |
