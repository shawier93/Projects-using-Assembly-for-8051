# Booking and Pricing

[Back to portfolio](../README.md)

Calculate charges from selected options and examine the stock or balance checks.

## Applications

| Application | Description |
| --- | --- |
| [Coffee Machine](coffee-machine/README.md) | Choose a drink and options, calculate its price, and process the credit available for the purchase. |
| [Insurance Quotation](insurance-quotation/README.md) | Calculate an example policy price from a category and selected options. |
| [Category-Based Service Pricing](service-pricing/README.md) | Calculate a service charge from a category, optional extras, quantity, and a final adjustment. |
| [Gold and Silver Ticket Booking](ticket-inventory-and-billing/README.md) | Select gold or silver tickets, calculate the charge, and update the stored number of tickets. |
| [Television Order Pricing](television-order-pricing/README.md) | Build a television order price from a brand and optional services. |
| [Gym Membership Booking](gym-membership-booking/README.md) | Select a membership plan and billing term, then use the corresponding price and availability. |
| [Date Based Discount](date-based-discount/README.md) | Choose a discount tier from a day value and calculate the amount payable. |
| [Access Code and Balance Update](access-code-and-balance/README.md) | Compare an entered code with a stored code and conditionally add an amount to a balance. |
